# Lecture 3 · Random Variables

📄 **[Handwritten notes](lecture03_random_variables.pdf)** (64 pages)

## Outline

- Random variables as maps X: Ω → ℝ, discrete and continuous
- PMF, CDF and PDF, and how they relate
- Discrete distributions: Bernoulli, binomial, categorical, multinomial
- The Poisson distribution, derived from first principles through its differential equations
- Continuous distributions: uniform, exponential (memorylessness), normal and standardization
- Bivariate distributions: joint, marginal and conditional PMFs and PDFs, bivariate CDF
- Functions of random variables
- Expectation, variance and covariance, with their properties derived
